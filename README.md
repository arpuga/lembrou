# lembrou.

Grava as reuniões do seu computador, transcreve no próprio PC e escreve a ata, com quadro de ações e documentos.

Este repositório publica só os **instaladores**. O código-fonte é privado.

## Baixar

Abra a [última versão](../../releases/latest) e baixe:

- **Lembrou-Setup-x.y.z.exe**: o programa para Windows 10 e 11.
- **lembrou-x.y.z.apk**: o app para Android (grava reuniões presenciais e mostra documentos, cards e atas).

O instalador do Windows atualiza por cima da versão anterior e mantém suas reuniões e dados.

## Avisos de versão nova

O próprio programa avisa quando há uma versão nova. Se quiser também por e-mail: clique em **Watch**, depois **Custom** e marque **Releases**.

## Se o Windows avisar

Pode aparecer a tela azul "O Windows protegeu o seu computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.
